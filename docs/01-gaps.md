# 凑合输入法 — 差距分析（还差什么）

> 定位：MVP 已验证"能打字"（TSF→IPC→RIME→候选→上屏 全链路通），
> 本文列出从 MVP 到"敢日常使用的输入法"之间的差距。
> 对标基准：搜狗输入法、微信输入法（本机/公开资料）。

---

## 1. 功能完整性缺口

| # | 缺口 | 现状 | 影响 | 优先级 |
|---|------|------|------|--------|
| 1 | **中英文快速切换** | 仅有 ascii_composer（Caps_Lock 配置在 default.custom.yaml） | 日常中英混输体验差，无 Shift 临时英文 | P0 |
| 2 | **候选翻页交互** | 仅键盘翻页（`[` `]` / PageUp/Down 由 RIME 处理），无鼠标滚轮/点击 | 鼠标用户无法操作候选窗 | P1 |
| 3 | **多方案切换 UI** | 有 switcher 热键（Control+`），但用户不可见方案列表 | 换方案只能靠热键记忆 | P1 |
| 4 | **主题/皮肤系统** | 候选窗颜色从单一主色推导（get_colors），无多主题 | 界面精致度上限低 | P1 |
| 5 | **深色模式** | 无（不跟随系统） | 夜间使用刺眼 | P1 |
| 6 | **模糊音** | pinyin_simp 未启用模糊音配置 | 部分用户输入习惯（n/l、zh/z 不分）无法用 | P2 |
| 7 | **用户词典/自学习** | RIME 有用户词典机制，未验证/未配置自定义词典路径 | 生僻词、专业词无法积累 | P2 |
| 8 | **简繁切换** | 拼音方案无简繁；wubi86_trad 有但未启用 | 繁体需求无法满足 | P2 |
| 9 | **符号/表情快捷输入** | symbols.yaml 存在但未验证触发 | 常规符号靠英文键盘模式 | P2 |
| 10 | **设置项覆盖** | 设置只有：字号、候选数、横竖排、字体、主色 | 缺：候选窗位置策略、翻页键、中英切换键 | P2 |
| 11 | **触控/触屏支持** | 无（TSF 只处理键盘事件） | 触屏设备不可用 | P3 |
| 12 | **辅助功能** | 无 UIA 暴露（候选窗是自绘 DComp 窗口） | 读屏软件用户不可用 | P3 |
| 13 | **多语言界面** | 仅中文 | 国际化缺失 | P3 |
| 14 | **云词库/联网** | 无（纯离线，RIME 架构决定） | 新词跟不上——但这是**隐私卖点**，建议做"可选云同步"而非默认 | P3 |

## 2. 工程化缺口

| # | 缺口 | 现状 | 影响 | 优先级 |
|---|------|------|------|--------|
| 1 | **release 构建** | 全部为 debug 构建（server 25MB Private / 逐键 2.3ms） | 性能基线不代表最终交付水平 | **P0** |
| 2 | **安装器** | 仅有 install.ps1（PowerShell 脚本） | 无卸载入口、无开始菜单快捷方式、无版本升级 | P1 |
| 3 | **代码签名** | 无 | SmartScreen "未知发布者"警告 | P1 |
| 4 | **CI/CD** | 无 | 换机器/换人无法复现构建 | P1 |
| 5 | **自动化测试** | 无单元/集成测试 | RIME 回归风险高（词典/配置改动无法验证） | P1 |
| 6 | **崩溃转储** | 无 WER 配置、无崩溃处理 | 用户侧故障无法定位 | P2 |
| 7 | **日志治理** | server 日志无轮转、INFO 级逐键输出（性能开销） | 长跑磁盘膨胀 + 拖慢输入 | P0 |
| 8 | **升级机制** | 无 | 用户无法自动更新 | P2 |
| 9 | **性能回归门禁** | perf3 手动跑 | 优化后无法防止回退 | P2 |

## 3. 已知技术债（已识别）

| 项 | 描述 | 处置 |
|----|------|------|
| `lua_translator` 缺失 | librime 未编译 Lua 插件，部分方案（如带 lua 的 rime-zhung）不可用 | 后续 librime-sys2 加 `-DBUILD_LUA` 编译 Lua 插件 |
| Escape 后首键 8ms | Esc 清空 composition 触发候选窗销毁，下一次按键重建 Direct2D 窗口 | 延迟销毁窗口 / 复用 RenderedView |
| 逐键 INFO 日志 | 每键 5-10 行 tracing INFO（IPC + UI 渲染） | release 默认 `RUST_LOG=warn`，开发时再开 info |
| wubi 词典残留 | rime-wubi 仓库仍含全部五笔词典文件（未编译，仅占源码体积） | 可裁剪方案数据，但保留便于用户切换五笔 |
| `page_size=5` 硬编码 | default.custom.yaml 写死候选数 5，与设置页"候选数"重复 | 设置值应写入 custom.yaml 的 patch |
| `.cargo/config.toml` 未入库 | 被上游 gitignore，内含 libximecore 本地 patch 路径 | 需在 README 写明构建步骤，否则换机器无法构建 |

## 4. 与竞品的量化差距（当前 debug 基线 vs 目标）

| 指标 | 当前（debug） | 目标（release+优化后） | 搜狗/微信参考 |
|------|--------------|----------------------|--------------|
| 常驻内存（Private） | 25.2 MB | **< 12 MB** | 搜狗多进程 150-400MB；微信输入法 80-150MB |
| 逐键延迟 p50 | 2.3-2.9 ms | **< 1.5 ms** | 5-15 ms（公开评测量级） |
| 首码延迟 p50 | 1.8-2.3 ms | **< 1 ms** | — |
| 候选窗渲染 | 每键全量重绘 | 增量重绘 + GPU 动画 | GPU 加速 |
| 启动到可输入 | deploy 0.4s + 引擎初始化 | 常驻进程，秒开 | 秒开 |
